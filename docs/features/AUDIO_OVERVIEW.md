# Audio Overview

Le README décrit un script dialogué à deux voix ElevenLabs, des formats/durées configurables, des pauses, un mixage stéréo 44,1 kHz et une normalisation -16 LUFS / -1,5 dBTP. Le résultat est un MP3 privé avec lecteur, vitesse réglable et téléchargement.

Variables worker : ELEVENLABS_API_KEY, AUDIO_OVERVIEW_HOST_VOICE_ID, AUDIO_OVERVIEW_GUEST_VOICE_ID, AUDIO_OVERVIEW_TTS_MODEL, FFMPEG_PATH. Le README indique que l'implémentation est sur branche dédiée et que validation locale/benchmark TTS restent à faire.
