# Paramètres des modèles IA

La configuration serveur documente OPENROUTER_CHAT_MODEL et les paramètres d'embeddings. Le worker permet openrouter, voyage ou mistral. Les embeddings doivent rester compatibles et de dimension 1024.

La présence d'une interface permettant de choisir un modèle par fonctionnalité et d'afficher compatibilité/gratuité n'a pas été vérifiée.
