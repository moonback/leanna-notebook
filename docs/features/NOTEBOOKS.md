# Notebooks

Le notebook regroupe sources, sélection du corpus, conversations, notes et artefacts. Le README décrit un tableau de bord avec vues tous/les miens/partagés, recherche, renommage et suppression.

Le partage privé distingue lecteur et éditeur. Les liens peuvent autoriser lecture et chat ou chat seul. La copie, si autorisée par le propriétaire, reprend les sources prêtes, passages indexés, guides et artefacts prêts, mais pas les conversations, notes ni partages.
