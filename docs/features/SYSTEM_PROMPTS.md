# Prompts système

L'audit n'a pas confirmé de gestionnaire UI permettant de consulter et modifier l'ensemble des prompts système, ni le mécanisme d'override, sauvegarde ou réinitialisation. Voir le [catalogue IA](../AI_PROMPTS_CATALOG.md).

Toute personnalisation doit séparer les préférences utilisateur des instructions système non modifiables (sécurité, autorisations et isolation).
