# Ajouter des sources

Ajoutez un PDF, document Office, EPUB, texte, CSV, audio, page web, texte collé ou note. La limite indiquée par le README est de 200 Mo. Le traitement est asynchrone : attendez l'état prêt avant d'interroger la source. Les PDF scannés sans texte sélectionnable ne bénéficient pas d'OCR selon le README.
