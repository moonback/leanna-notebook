# Utiliser le chat

1. Ouvrez un notebook et sélectionnez les sources pertinentes.
2. Posez une question précise.
3. Consultez les citations numérotées.
4. Ouvrez une citation pour revenir au passage correspondant.
5. Enregistrez éventuellement une réponse sous forme de note.

Le texte partiel et les citations sont conservés si vous arrêtez une réponse, selon le README.
