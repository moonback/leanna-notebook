# Bien démarrer

1. Créez un compte ou connectez-vous par email/mot de passe ou lien magique.
2. Créez un notebook depuis le tableau de bord.
3. Ajoutez des documents ou d'autres sources prises en charge.
4. Attendez que les sources soient prêtes.
5. Sélectionnez les sources et posez une question au chat.
6. Utilisez le Studio pour générer un rapport, une fiche, un quiz ou une carte mentale.
