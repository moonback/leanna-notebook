# Présentation

Leanna Notebook est une application de recherche documentaire assistée par IA. Les utilisateurs organisent des sources dans des notebooks, interrogent ce corpus et peuvent vérifier les réponses grâce à des citations rattachées aux passages d'origine. Le Studio produit des supports de synthèse et de révision.

## Public et usages
- Étudiants : fiches, quiz, cartes mentales et révision.
- Professionnels : synthèse et exploration de dossiers documentaires.
- Équipes : partage privé avec rôles lecteur/éditeur.

## Principes
1. Regrouper les sources dans un notebook.
2. Extraire, segmenter et indexer les contenus via un worker.
3. Rechercher dans les sources sélectionnées.
4. Générer une réponse contextualisée.
5. Contrôler les citations et relier les extraits aux documents.

## État conservateur
Le README décrit notebooks, sources, chat/citations, rapports, fiches, quiz et cartes mentales comme disponibles. Il indique que la facturation est simulée, que l'envoi d'emails applicatifs n'est pas branché, que Google Drive et les infographies restent à faire. Les fonctionnalités vocales Leanna/Roxane et le gestionnaire de prompts personnalisés n'ont pas été confirmés par les fichiers consultés.
